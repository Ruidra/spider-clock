# Spider Clock APK

A beautiful animated spider clock face wrapped as an Android APK.

## Building Locally

Requires:
- Java 17+
- Android SDK (API 34)

```bash
cd android
./gradlew assembleDebug
```

The APK will be at `android/app/build/outputs/apk/debug/app-debug.apk`

## GitHub Actions

This repo includes a GitHub Actions workflow that automatically builds the APK on every push to main/master. Download the APK from the Actions artifacts.

## Features

- Animated spider clock with moving gears
- Hour, minute, and second hands with smooth animations
- Morphing spider face animations
- Full screen immersive experience
- Works offline (all assets bundled)
